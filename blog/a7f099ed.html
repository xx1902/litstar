如何把自己喜欢的ip做成 Codex 桌宠

桌宠社区网址

Petdex：https://petdex.dev/zh

Codex Pets：https://codex-pet.org/zh/codex-pets/

Codex 可以上传自己的内容来做一个会动的桌宠，可以跟着 Codex 的工作状态做出反应

流程分两步：

  1. 根据参考图片生成基础 IP 形象
  2. 把基础 IP 图上传给 Codex，生成整套桌宠动画

一、生成基础 IP 形象

先在 Codex 里新建一个普通对话（或者其他平台），把参考图片或者想法发送，最好只有一个主体，把角色的轮廓、发型、眼睛、配色、服装和整体气质确定下来，再继续制作动画。

提示词：

生成满意后，把这张基础 IP 图保存下来，桌宠最终显示得比较小，所以不建议堆积太多复杂纹理和装饰。基础形象的轮廓越清晰，做成桌宠后的辨识度通常越高。

二、让 Codex 生成桌宠

基础 IP 图确认后，打开 Codex 的宠物设置：Settings → Pets → Create

上传刚刚生成的基础 IP 图，再输入下面这段要求：

接下来，Codex 会继续生成不同状态的动作，例如：待机 左右移动 挥手 跳跃 等待确认 任务运行中 检查结果 任务失败

其中：

行数 状态名 通常出现的时机
第 1 行 idle 没有任务时，桌宠安静待机
第 2 行 running-right 向右拖动或移动桌宠
第 3 行 running-left 向左拖动或移动桌宠
第 4 行 waving Codex 开始响应、启动任务时；
第 5 行 jumping 鼠标悬浮到桌宠身上时；
第 6 行 failed 任务失败、取消、被阻塞或发生错误时
第 7 行 waiting Codex 等待你确认、授权、选择或补充信息时
第 8 行 running Codex 正在处理任务、思考或执行工作时；
第 9 行 review 工作完成、准备让你查看结果时
第 10–11 行 look 根据鼠标相对桌宠的位置，朝不同方向看
– 这个好像暂时没效果

这里如果是第三方 API 登录的话，还需要单独创建一下 image2 的 skill，用来代替官方的生图，用账号登录可以忽略。

生成完成后，桌宠文件通常会出现在：~/.codex/pets/你的宠物名称/

其中最关键的是两个文件：pet.json spritesheet.webp

然后回到：Settings → Pets 选中刚刚生成的角色，再点击唤醒，你的个人 IP 就会出现在桌面上。

注意

桌宠需要制作多组动作和表情，所以生成速度会比普通对话慢，会消耗更多使用额度。建议先把基础 IP 图调整满意，再开始生成桌宠。（要很久，两个小时）
